## 🌐 About | درباره پروژه

**English**

Tarikhkhaneh is a browser-based image editor designed to provide essential image editing and export tools in a clean, desktop-inspired workspace.

It allows users to resize, crop, rotate, adjust, and enhance images, with support for custom dimensions, print-ready settings, and multiple export formats.

All image processing happens directly on the user's device, without uploading images to an external server.

**فارسی**

تاریکخانه یک ویرایشگر تصویر تحت وب است که مجموعه‌ای از ابزارهای کاربردی ویرایش و خروجی گرفتن از تصاویر را در محیطی ساده و حرفه‌ای ارائه می‌دهد.

با استفاده از این ابزار می‌توان تصاویر را تغییر اندازه داد، برش زد، چرخاند، فیلترگذاری کرد و تنظیمات مختلفی روی آن‌ها اعمال کرد. همچنین امکان تعیین ابعاد سفارشی، تنظیمات مناسب چاپ و دریافت خروجی در فرمت‌های مختلف وجود دارد.

تمام پردازش تصاویر مستقیماً روی دستگاه کاربر انجام می‌شود و نیازی به بارگذاری تصاویر روی سرور خارجی نیست.

## 📦 Export Options | فرمت‌های خروجی

| Format | کاربرد |
|---|---|
| PNG | تصاویر با پشتیبانی از شفافیت |
| JPEG | تصاویر با حجم کمتر |
| WebP | فرمت مدرن و بهینه وب |
| PDF | خروجی مناسب اسناد و چاپ |

Additional export settings include image quality, background color, resampling, and DPI metadata where supported.

تنظیمات خروجی شامل کیفیت تصویر، رنگ پس‌زمینه، روش بازنمونه‌گیری و ثبت اطلاعات DPI در فرمت‌های پشتیبانی‌شده است.
